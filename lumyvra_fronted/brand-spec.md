# Lumyvra 原型还原

## 当前首页方向

后续用户明确要求增强宣传吸引力、减少模板感并加入 Three.js，因此首页已采用新的音乐品牌方向：炭黑 / 纸白 / 黄绿色强调，实时粒子声场和可试听的本地合成片段。首页不再受下方旧版原型逐像素还原目标约束；其余页面保留旧设计。详见 docs/homepage-direction.md。

## 原始参考

以 reference/ai_music_assets/ui_references 中的 11 张图为视觉依据。完整历史聊天不可读取，网站名暂采用工作目录名称 Lumyvra，原图上的名称为 MelodyAI。

- 类型：AI 音乐静态多页面原型；面向音乐创作者；保持原稿设计。
- 五项标尺：布局变化 2，动效 3，信息密度 6，素材依赖 9，参考保真 10。
- 色彩：背景 #040e1b；面板 #0b172a；边框 #1e2c44；正文 #f4f4ff；次级 #97a2bd；强调 #41c9f6 / #9270ff / #df52ed。
- 字体：Segoe UI / PingFang SC / Microsoft YaHei；正文 14px，标题 32–56px。
- 间距：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px。卡片圆角 12px，输入 8px，按钮 24px。
- 动效：160–250ms 状态反馈；生成页粒子旋转；遵循 prefers-reduced-motion。
- 视图：桌面为主，保留手机单列布局；不加入原型以外的样式调节面板。
- 原型没有独立 logo，使用声波符号加文字复现该结构。
- 当前运行素材：public/assets/hd。主视觉和宣传插画为 1536×1024，六张封面为 1254×1254；通过内置 imagegen 参考图重建，移除烘焙的文字和按钮。public/assets/banners 与 public/assets/covers 保留最初裁切素材，不用这些小图承担当前主视觉。重建细节不等于无损恢复原图。
- 参考图里的作品名称、用户与数字属于演示内容；不接入生成、登录、支付或音乐服务。

首页承担入口与作品发现；创作页为工具布局；播放页为沉浸布局。以普通笔记本观看距离设计，深色安静基底搭配高饱和插画。按原图信息层级布局，不使用整张页面截图替代网页。
