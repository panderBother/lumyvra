# 全站视觉统一

按照用户要求，将首页的炭黑、纸白、黄绿色推广到其余页面。保留原有路由、表单参数与演示交互。

## 页面结构

- 所有页面移除旧原型的居中圆角外框，页面背景与外壳占满浏览器；主内容随可用宽度展开，桌面保留 32–64px 页边距，手机保留 18–22px。
- 创作页：与全站一致的顶部导航和页边距，主要编辑区与灵感栏；手机转单列。创作与生成过程页不再显示重复的左侧工具栏。
- 社区：大封面三列作品网格、明确的创作入口与筛选；手机两列。图片 sizes 随新布局同步扩大。
- 个人中心：作品库标题、个人资料、横向栏目导航与分隔线列表，不再采用侧栏布局。作品、收藏、记录、设置集中在资料下方，订阅会员保留为右侧轻量链接；窄屏可横向滚动栏目导航。
- 生成过程、结果和播放器：统一状态色、封面、歌词、播放控件。结果附栏在窄屏转为下方内容。
- 会员：唱片图形与大标题，平面订阅卡；保留演示提示。
- 登录：左侧摄影感背景与右侧表单；手机图片转至表单上方。
- 创作灵感、关于、帮助：分别采用图文首屏、品牌故事与双栏问答，保持相同色彩、字体和按钮规范。

## 样式入口

`layout.tsx` 顺序引入 `globals.css`（既有组件结构）、`music-landing.css`（首页与共享导航）、`studio-theme.css`（统一主题及各页面布局）。旧 `reference-fidelity.css` 保留作历史参考，不再加载，避免旧外框覆盖全屏布局。

字体由根布局引入本地 Fontsource 包，中文使用 Noto Sans SC Variable，拉丁字母与数字使用 Manrope Variable；通过 unicode-range 按需加载分片。标题采用 500 字重，正文 400，调整字距并保留系统字体回退。

使用现有高清 WebP 素材，不对图片添加模糊滤镜。色彩调整使用 saturation / brightness；文字与控件仍为真实 HTML。主页面继续服务端渲染，交互仍由既有客户端组件负责。

浏览器截图验收尚未完成，构建与 HTTP 检查不代表视觉验收或交互点击测试。

本轮验证：生产构建、ESLint 通过；首页及全部内页共 13 个 URL 返回 HTTP 200（含歌词结果分支）；创作页 SSR 保留传入的 prompt；响应样式包含新的共享主题。
