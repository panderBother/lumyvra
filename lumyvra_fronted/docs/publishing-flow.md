# 创作灵感、草稿与发布

## 用户流程

1. `/promo` 浏览六个精选示例以及当前浏览器中已发布且允许做同款的作品。支持分类、关键词搜索与展开创作提示词。
2. 做同款通过 `/create?template=…`（精选）或 `/create?remix=…`（本地作品）带入提示词、方式、风格、情绪、时长、封面与来源。不会修改原作品。不存在、未发布或未允许做同款的来源显示不可用提示。
3. 创作页支持先保存草稿。开始生成也先保存，成功保存后才跳转；约 8 秒完成演示生成，将 `ready` 标记为 true，仍为未发布草稿。提前离开仍可从草稿箱继续。
4. `/result?id=…` 查看内容、修改名称与介绍、保存草稿。点击发布展开确认表单，「允许其他人做同款」默认不勾选，明确说明将展示提示词和创作参数。
5. 确认发布后进入个人中心「我的作品」和作品广场的「新发布 · 本地演示」。勾选允许做同款的作品同时进入灵感页及创作页右侧。
6. `/profile?tab=drafts` 为未发布草稿；`works` 为已发布；`history` 包含全部。各列表支持按创作方式筛选，个人统计使用实际本地数量。

## 数据与边界

- 使用 `localStorage` 键 `lumyvra.works.v1`，跨页面、刷新保留；同源其他标签页通过 storage 事件更新。服务端先渲染示例及加载状态，避免读取浏览器存储造成 hydration 差异。
- 这是既有静态原型的本地发布模拟，未接入身份验证、服务器、真实音乐生成或公共社区；其他设备和真实其他用户不可见。页面明确说明这一点。清理浏览器站点数据会移除本地作品。
- 原始文本和创作参数保留。非歌词模式输出仍为固定示例歌词，封面来自本地素材，没有伪造音频下载或真实生成结果。
- 未完成生成不可发布；发布操作幂等；修改已发布作品通过新建同款草稿进行。数据损坏或存储满时显示错误，不覆盖旧数据、不提前跳转、不报告发布成功。
- 源码：`src/lib/works.ts` 为存储和状态变更，`use-works.ts` 为订阅，`inspiration.ts` 为精选来源。

## 验证

`npm run test:works` 覆盖草稿刷新恢复、发布前置条件、是否进入灵感页、重复发布、继续草稿与独立同款、存储失败和损坏数据保护。生产构建与 ESLint 已通过。浏览器点击与截图验收尚未完成。
