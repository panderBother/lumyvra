# Lumyvra

基于素材包原型制作并逐步改版的 Next.js AI 音乐网站静态原型。全站采用炭黑、纸白和黄绿色，页面外壳铺满浏览器，保留创作工作台、音乐作品与沉浸播放器。

首页加入 Three.js 实时粒子声场、可暂停动效、24 秒真实本地合成试听，以及可将灵感直接带入创作工作台的输入框。其他页面已统一配色、导航、按钮与响应式布局，并按工作台、作品库、订阅、问答等用途分别排版。详见 [首页改版说明](docs/homepage-direction.md) 与 [全站视觉规范](docs/site-design-system.md)。

全站字体采用本地 Noto Sans SC Variable 与 Manrope Variable。首页声场支持鼠标推开、按住拖动、点击扩散和移开回弹；触屏可轻触触发波纹。暂停动效或开启系统减少动画时，粒子保持静态。

创作灵感页现支持搜索、分类、查看提示词和做同款。新增本地草稿、发布确认、允许做同款选项与作品广场联动；个人中心区分草稿和已发布作品。详见 [发布流程说明](docs/publishing-flow.md)。

## 高清素材与比例修复

已针对原始缩略图被放大导致的模糊进行修复：首屏和宣传背景替换为 1536×1024 的参考图重建素材，六张作品封面替换为 1254×1254 的无文字、无播放按钮版本。统一保留真实 HTML 文案与交互，修正响应式图片 `sizes`，高清图片使用 90 质量，取消宣传图的 150%–210% 过度放大。

最初按原型进行的比例修复及素材提示词、已知限制保存在 [高清修复记录](docs/hd-restoration.md)。后续品牌改版以用户最新要求为准，不再沿用旧外框与蓝紫配色。原压缩包及裁切素材保留；重建细节不等于原始设计像素。

## 运行

需要 Node.js 20.9 或更高版本，本项目已在 Node.js 22 下构建。

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。生产运行：

```bash
npm run build
npm run start
```

## 实现方式

- Next.js 16.4 App Router、React 19、TypeScript、原生 CSS、Lucide 图标。
- 页面与布局默认使用 Server Components，交互组件单独标记 `use client`；客户端组件的初始内容同样预渲染。
- 固定内容采用构建时预渲染，带查询参数的社区、创作流程、结果、个人中心页面按请求服务端渲染。首屏文本与作品不依赖客户端请求才能显示。
- 使用本地图片和 `next/image`，不依赖远程图片、外部字体或 CDN。首页主视觉优先加载。
- 各页包含标题与描述；提供键盘焦点、表单标签、跳过导航、移动端布局与减少动画支持。
- 服务端 / 客户端组件划分参考 [Next.js 官方文档](https://nextjs.org/docs/app/getting-started/server-and-client-components)。

压缩包已保留，未删除原始素材。历史 ChatGPT 对话读取工具在本次环境不可用，因此使用压缩包内的 11 张参考图作为还原依据。原图品牌为 MelodyAI，本实现按目录名暂用 Lumyvra；修改 `Logo`、站点 metadata 和页脚可调整名称。此实现没有验证名称或域名是否可注册。

## 静态原型边界

- 作品、用户、统计数字、价格和会员权益均为演示内容。
- 生成进度约 8 秒后展示固定示例作品，不调用 AI 服务。原型不创建真实音乐。
- 素材包没有音频，因此作品详情播放器仅提供控件演示；页面明确提示未接入音频，下载按钮不生成虚假音频文件。首页独立试听提供本地 Web Audio 合成片段，明确标注「合成音色试听」，不冒充列表中的完整作品。
- 登录、注册和付费不连接后台、不收款、不发送表单数据。
- 创作草稿、作品信息和发布状态通过浏览器本地存储保留；发布仅模拟展示在同一浏览器内，不提供跨用户或跨设备保存。昵称和收藏交互仍为页面内演示。
- 原型图是小尺寸拼图，初始裁切素材包含按钮、文字和 UI 边缘。当前使用的主图和六张封面已通过参考图重建，图片不再包含这些 UI 元素；由于缺少原始高清设计稿，不能声称逐像素一致。
